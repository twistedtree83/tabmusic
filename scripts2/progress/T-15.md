# T-15 — Backgrounded window: pause rendering, keep the heartbeat

**Issue:** #15  **Commit:** a216140  **Status:** shipped

## What shipped

`frame.js` now cancels the animation frame loop when the document goes hidden and restarts it
when it comes back. The heartbeat, the audio and the roster are all untouched: a window nobody is
looking at stops drawing and keeps singing.

## Decisions made

- **The `visibilitychange` listener is attached lazily, on the first `onFrame` subscription.**
  A module-level listener would attach on the narrow-screen path too, where nothing subscribes;
  T-13's test asserts that path builds nothing, and this keeps that true.
- **`start()` refuses to run while `document.hidden`**, so a subscription made in a
  hidden window does not quietly start a loop that the pause was meant to prevent.
- **No state is reset on pause or resume.** The stage's sibling positions live in its own map and
  are simply not advanced while hidden, which is what makes "resumes rather than resets" true by
  construction rather than by care.
- **Visibility is driven in tests by redefining `document.hidden` and dispatching the event.**
  Playwright has no API for backgrounding a page, and relying on a real background would test the
  browser rather than the piece. This exercises exactly the handler this project owns.
- **Frames are counted by wrapping `requestAnimationFrame` in an `addInitScript`,** the same
  technique T-13 used for constructors. Note the page must be reloaded after the init script is
  added if it was opened first.
- **The resume test waits for the sibling drift to settle before taking its baseline.** A row
  captured mid-lerp moves on its own and would prove nothing about the pause; it passed alone and
  failed under full-suite load until the wait was added.

## Deliberately left

- **Real background throttling is not tested**, only our response to the event. The 3000 ms prune
  timeout is the mitigation for a genuinely clamped timer, and T-03 unit-tests that directly.
- **Reduced motion is still not honoured.** **T-14**, which is now the last piece of behaviour.
