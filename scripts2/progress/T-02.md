# T-02 — Walking skeleton: build, verify gate, entry gate screen, CI

**Issue:** #2  **Commit:** e187016  **Status:** shipped

## What shipped

An empty repository is now a project that builds to one self-contained
`dist/index.html` and has a working four-stage verify gate. The entry **gate** screen renders —
eyebrow, wordmark, hairline, standfirst, "Lend a voice", "sound begins on your gesture" — and
nothing of the **stage** exists before the gesture. Clicking or keying the control clears the
gate and calls back into `src/main.js`, where T-03 will hang the peer layer.

## Decisions made

- **Playwright is pinned to `^1.62.0`** because chromium-1234 is already in the local
  `~/Library/Caches/ms-playwright`. Bumping the major will trigger a browser download on the
  next machine that runs the gate.
- **`workers: 1`, `fullyParallel: false`.** Presence assertions are wall-clock sensitive; a
  second worker makes prune timings flaky rather than wrong.
- **`tests/e2e/windows.js` is the only way to open more than one window.** `openWindows(context, n)`
  creates every page from the test's own `context` fixture. Separate Playwright contexts do not
  share a BroadcastChannel, so a multi-window test written with `browser.newContext()` twice
  passes while proving nothing. `tests/e2e/context.spec.js` proves the helper works by sending a
  probe message between two pages — that assertion is the foundation T-03 stands on, so do not
  delete it when the real presence tests land.
- **`window.__tabchoir` does not exist yet.** T-05 introduces it. Tests here assert on DOM only.
- **CSS lives in `src/styles.css`** and is imported from `main.js`. It does not count against the
  650-line JavaScript budget, which is deliberate — layout and palette should not compete with
  logic for the budget.
- **The wordmark is `Tab Choir` with `white-space: nowrap`**, not `Tab&nbsp;Choir`. The NBSP
  broke accessible-name matching in Playwright, and nowrap achieves the same typography.
- **`tsconfig` runs `strict: false`.** With `strictNullChecks` on, every `querySelector` in the
  project needs a cast, which costs more lines than it saves. Type a DOM query explicitly when
  you need its event map — `gate.js` casts `.join` to `HTMLElement` so `keydown` yields a
  `KeyboardEvent`.
- One test was corrected rather than the code: the "never says tab" assertion stripped the title
  case-sensitively, but CSS renders the wordmark uppercase so `innerText` returns `TAB CHOIR`.
  The strip is now case-insensitive. The assertion itself is unchanged and still fails on any
  other use of the word.

## Deliberately left

- The click handler's callback body is empty. **T-03** owns what happens after the gesture.
- The narrow-screen branch is not present — `main.js` renders the gate unconditionally.
  **T-13** owns the viewport check and must insert it before `renderGate`.
- No GitHub Pages deploy workflow; only `verify.yml`. **T-16** owns deployment.
- Font loading is not asserted by any test. The `<link>` is present and the fallback stack is
  declared; whether Google Fonts actually resolves is not something the gate should police.
