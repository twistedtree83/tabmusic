# T-11 — The hint: a one-way copy state machine

**Issue:** #11  **Commit:** 550934d  **Status:** shipped

## What shipped

The hint's three-state machine, which only moves forward: *"You are one voice. Open this page in
another window."* → *"Now move your windows."* → gone. The second line fades out about nine
seconds after it appears and never returns, whatever the roster does afterwards.

## Decisions made

- **`seenPeer` lives in the overlay closure.** Nothing is persisted — a test asserts
  `localStorage`, `sessionStorage`, `location.search` and `location.hash` are all empty. A
  reloaded window is a new window and starts at the first line, which is the specified behaviour
  and also the only one that keeps the piece honest about having no memory.
- **`say(line)` fades out, swaps, fades in**, with the swap on a `FADE_MS` timeout that matches
  the CSS transition. The first line is set directly rather than faded in from nothing, so a
  lone window is not staring at an empty screen for 1.6 s.
- **The nine-second retreat is scheduled once**, guarded by a `lingering` boolean. It is
  `FADE_MS + LINGER_MS` from when the second line was requested, so the countdown starts when
  the line is actually readable rather than while it is still fading in.
- **Once the line is hidden it stays hidden**, because `say()` returns early when the text is
  already what was asked for — so a later roster change re-runs the update without touching
  opacity. That is load-bearing: without the early return, every join and leave would flash the
  line back.
- **`lingering` is a boolean, not a timer handle.** `setTimeout` returns `Timeout` in the Node
  types this project type-checks against, which does not assign to `number`. Do not store a
  timer id in a `let x = 0` here.
- **The fade test samples opacity in-page from before the trigger.** Third time this project has
  needed that shape — the glide (T-06), the drift (T-09), and now the hint. If you are asserting
  that something is gradual, start sampling before you cause it.

## Deliberately left

- **The listener's hint is still the ordinary copy.** **T-12** owns the plain-words version and
  the status line that goes with it.
- **The fade ignores `prefers-reduced-motion`.** **T-14** makes it instant; `FADE_MS` is the
  constant it needs.
