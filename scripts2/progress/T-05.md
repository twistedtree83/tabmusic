# T-05 — Audio engine: lazy context, procedural reverb, bus, analyser

**Issue:** #5  **Commit:** fe71c48  **Status:** shipped

## What shipped

`src/engine.js`: one `AudioContext` per window, built synchronously inside the click handler,
with `bus`, `analyser`, a convolution reverb and a feedback echo. The impulse response is
computed — 3.5 s of noise under an exponential decay, rendered through a lowpass in an
`OfflineAudioContext` — so the single-file artefact fetches nothing.

`src/hook.js`: `window.__tabchoir`, a frozen snapshot per read. The e2e suite now asks the piece
what it is doing instead of parsing a `<pre>`.

Nothing is audible yet. `voiceCount` is 0 and stays 0 until T-06.

## Decisions made

- **`startEngine()` is synchronous and returns `{ ctx, bus, analyser, ready, impulseSeconds }`.**
  The context and its `resume()` must both happen inside the gesture task; `await`ing the impulse
  first would push them past it and leave the context suspended. The impulse lands a few
  milliseconds later via `engine.ready`, and the reverb is simply silent until it does. **Do not
  make this function `async`.**
- **`decayingNoise(ctx, seconds)` takes its context rather than making one**, so it can be
  called in Node with a stub that implements only `sampleRate` + `createBuffer`. The decay lives
  in the buffer, not in a gain envelope, which is what makes it testable without an audio
  device. `tests/unit/engine.test.js` asserts the tail decays monotonically tenth by tenth and
  that the last tenth is under a twentieth of the first.
- **The offline pass earns its place.** It is not ceremony for the sake of the spec: it bakes a
  2.6 kHz lowpass into the impulse so the room is darker than white noise and the convolver has
  less to chew at playback.
- **The room is strictly parallel.** `bus` connects to `destination`, `analyser`, `reverb` and
  `delay`; nothing connects back into `bus`. A discipline test asserts both halves of that,
  including the absence of any `*.connect(bus)`, because a return leg would put the room in
  front of the speakers and it would sound plausible.
- **The analyser taps the bus, not a voice.** Voices carry their own lowpass, so the bus is
  already post-filter. T-08 reads from `engine.analyser` and must not create its own.
- **`window.__tabchoir` is a getter returning `Object.freeze(read())`.** Fresh object per read,
  so a test cannot cache a stale one, and writes to it do not reach the engine. It ships in
  production on purpose.
- **`modulePreload: false` in `vite.config.js`.** Vite's preload polyfill left a `fetch(` in the
  build, which failed the "no network but fonts" assertion. There is nothing to preload in a
  single inlined file. If a future task re-enables code splitting, that assertion will fire
  again and it is right to.
- **`voiceCount` is hard-coded 0 in the hook.** T-06 replaces it with the real count.

## Deliberately left

- **No oscillators, no envelope, no glide.** **T-06** owns `Voice`.
- **`engine.ready` is exposed but nothing awaits it.** T-06 may want to, so a voice does not
  start dry; a couple of milliseconds of dry attack is not worth blocking on, so it is a
  judgement call for that task.
- **No `dispose()` on the engine.** Nothing closes the `AudioContext` on `pagehide`. **T-15**
  should decide whether that matters; a closing window is being torn down anyway.
- **Master level is `bus.gain.value = 0.9`, set before anything starts.** Setting `.value`
  *before* `start()` is how initial values are established and is fine. The T-06 discipline test
  must not flag these.
- **The `<pre>` dump is still the presence UI.** **T-08** replaces it.
